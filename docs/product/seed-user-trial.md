# 种子用户试用说明

本文件用于邀请第一批种子用户试用资产轨迹 MVP，并引导他们完成核心路径后提交有效反馈。

## 试用定位

资产轨迹当前是本地优先 MVP，用于记录资产、查看持仓和收益变化、理解资产变化来源，并沉淀投资复盘。

当前版本不提供投资建议、收益承诺、保本暗示、自动交易、券商同步或云端多设备同步。数据默认保存在用户当前浏览器本地，集中录入或重要修改后需要导出 JSON 备份。

## 邀请文案

### 简短版

我在做一个本地优先的个人资产追踪工具，想邀请你试用 10 分钟。

这次只需要完成一个任务：从空白状态添加至少两个资产，看看它能否帮你看清整体资产、主要分布和数据状态。

- 资产可以使用虚构或脱敏数据。
- 两个资产最好来自不同账户、市场或币种。
- 完成后请告诉我录入是否顺畅、结果是否容易理解、哪些数字让你不信任。

当前版本是 MVP，不连接券商，私人资产明细只保存在当前浏览器，也不提供投资建议。证券代码和市场会作为不关联用户的公共行情同步目标保存在服务端，历史窗口会发送给行情服务；数量、成本、账户、交易、备注和精确持有日期不会随行情同步上传。请只录入少量虚构或脱敏资产体验流程。试完后请点页面底部“用户反馈”，告诉我哪里卡住、哪里不可信、哪里值得继续做。

### 完整版

我在做一个叫“资产轨迹”的资产记录和投资复盘工具，想请你作为种子用户试用。

这个版本的重点不是行情推荐或交易建议，而是帮助个人投资者把分散的资产放到一个整体视图中：

- 当前整体投资资产大约是多少。
- 资产主要分布在哪些账户、市场、币种和类别。
- 哪些数据正常可信，哪些仍然缺失、过期、手动填写或使用估算。

当前是本地优先 MVP：

- 私人资产、交易、复盘和设置保存在你的浏览器本地，不作为私人资产明细上传。
- 证券代码和市场会作为不关联用户的公共行情同步目标保存在服务端，历史窗口会发送给行情服务，用于获取并持续维护公共价格、净值、汇率和证券基础信息。
- 不连接券商、银行或交易所。
- 不承诺实时行情或全市场覆盖。
- 所有收益、风险和图表仅用于记录与复盘，不构成投资建议。
- 请不要录入真实账户凭据、身份证明或完整敏感资产明细。

建议你用 10 分钟完成下面的唯一主任务，然后通过页面底部“用户反馈”把感受发给我。交易、深度分析、复盘和备份可以自由体验，但不影响这次任务是否完成。

## 10 分钟唯一主任务

1. 从空白状态进入资产页，添加至少两个虚构或脱敏资产。
2. 两个资产至少属于两个账户，或涉及不同市场、币种。
3. 回到总览，找出组合总值、主要持仓和至少两个你实际拥有的分布维度。
4. 判断哪些数据正常，哪些数据缺失、过期、手动填写或使用估算。
5. 点击页脚“用户反馈”，告诉我是否完成、花了多久、哪里卡住，以及你是否愿意继续维护这个组合。

## 可选观察

完成唯一主任务后，如果你还有时间，可以自由体验交易、深度分析、复盘和 JSON 备份。这些功能不计入首次任务是否成功，也不要求在 10 分钟内完成。

## 重点观察问题

请种子用户优先回答以下问题：

- 你是否完成了两个资产的添加？总共花了多久？
- 最主要的卡点在哪里？是字段看不懂、按钮找不到，还是不确定数据含义？
- 你认为当前总资产是多少？资产主要分布在哪里？
- 你能否识别正常、缺失、过期、手动或估算数据？哪个数字最让你不信任？
- 相比你原来的记录方式，这个整体视图是否更清晰？为什么？
- 你是否愿意继续维护这个组合？愿意或不愿意的原因是什么？

## 反馈入口说明

页面底部有“用户反馈”按钮。点击后会生成结构化反馈模板，并提供复制或邮件草稿发送能力。

反馈模板只包含试用概况统计，不会自动附带资产名称、金额、备份文件或具体持仓明细。

反馈时请不要发送：

- 完整 JSON 备份文件。
- 真实券商、银行、交易所账户凭据。
- 身份证、护照、银行卡等身份或支付信息。
- 完整真实资产明细。

## 内部判定标准

本轮种子用户试用只验证第一价值：用户是否愿意付出可接受的录入成本，获得清晰、可信的整体资产视图。内部记录必须覆盖：

- 完成或未完成；
- 首次录入耗时；
- 主要卡点和流失位置；
- 对总资产、主要分布和数据状态的理解；
- 与原有工具或方式的比较；
- 是否愿意继续维护组合及原因。

交易、深度分析、复盘、备份和付费问题只作为可选观察，不影响首次任务成功判定。3—5 名用户完成后再统一复盘，不根据单个反馈提前扩大功能范围。
