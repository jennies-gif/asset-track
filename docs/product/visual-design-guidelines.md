# 资产轨迹视觉规范（已废止）

- 状态：Deprecated
- 废止日期：2026-08-01
- 替代文档：[`docs/engineering/design-system.md`](../engineering/design-system.md)

本文件原先同时承载产品视觉原则、品牌色、字体、组件和实现 Token，现已停止作为独立规范使用。

废止原因：

- 原文的青绿色品牌体系与工程设计系统的金融蓝体系冲突；
- 原文的等宽数字字体与当前统一系统字体规则冲突；
- 原文将 `src/styles/app.css` 描述为 Token 源头，但当前真实基础 Token 位于 `src/styles/00-base.css`；
- 两份长期视觉规范会导致 AI 和开发任务继续生成不同品牌、组件与覆盖样式。

原文中仍然有效的产品原则，包括专业可信、冷静理性、数据可审计、隐私友好、克制语义色、金融图表与风险表达，已经合并到新的唯一规范中。

从本页废止起：

- 所有 UI、CSS、组件、图表、响应式和视觉评审任务统一读取 [`docs/engineering/design-system.md`](../engineering/design-system.md)；
- 不得引用本文件历史内容建立新的颜色、字体、圆角、组件或页面规则；
- 当前代码不因规范迁移而自动视为已经符合新规范，真实实现仍需按任务范围渐进验收和收敛。
